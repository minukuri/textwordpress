# WordPress Custom Theme Assignment
Custom Gutenberg blocks were created using register_block_type() with PHP render_callback functions. Each block uses index.js for editor fields and render.php to generate dynamic frontend output based on block attributes and WordPress data.

## Plugins Required
- Contact Form 7 and custom contact setting plugin

## Installation

1. Upload the theme to /wp-content/themes/.
2. Activate the theme from WordPress Admin.
3. Install and activate Contact Form 7.
4. Create a Contact Form 7 form and add its ID in the Consultation Form block.
5. Create Practice Area posts.
